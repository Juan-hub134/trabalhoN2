# SmartChef AI 

Aplicação web desenvolvida como parte do trabalho da disciplina de **Introdução à Inteligência Artificial**.

O **SmartChef AI** é um assistente culinário que utiliza um chatbot para auxiliar o usuário na criação de receitas a partir dos ingredientes disponíveis, buscando tornar o planejamento das refeições mais simples e reduzir o desperdício de alimentos.

##  Objetivo

O projeto teve como principal objetivo aplicar conceitos estudados na disciplina de Inteligência Artificial na construção de uma aplicação prática.

A proposta consiste em utilizar um chatbot capaz de receber informações fornecidas pelo usuário e gerar sugestões relacionadas à culinária, simulando a interação com um assistente virtual.

Além da implementação da inteligência do chatbot, foi desenvolvida uma interface web para tornar a aplicação mais acessível e apresentar visualmente o funcionamento do projeto.

##  Inteligência Artificial

A principal parte do projeto foi desenvolvida em **Java**, responsável pela implementação do chatbot e pela lógica de interação com o usuário.

O desenvolvimento dessa parte teve como foco compreender e aplicar os conceitos relacionados à utilização de Inteligência Artificial em uma aplicação real, desde o processamento da entrada do usuário até a obtenção e apresentação das respostas.

### Desenvolvimento com auxílio de IA

Durante o desenvolvimento do projeto, ferramentas de Inteligência Artificial também foram utilizadas como **ferramentas de apoio à programação**, principalmente na construção e aprimoramento da interface visual do front-end.

Esse uso é declarado de forma transparente: a IA foi utilizada como recurso auxiliar no desenvolvimento do front-end, enquanto a implementação do chatbot em Java constitui a principal parte desenvolvida para aplicação dos conhecimentos da disciplina.

Dessa forma, o projeto também representa uma experiência prática sobre diferentes formas de utilização da Inteligência Artificial no processo de desenvolvimento de software.
